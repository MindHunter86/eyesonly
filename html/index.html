news / example

Destroy tokens added

article

Published 2026-07-08 · Product update · 4 min read

Destroy tokens give senders and trusted recipients a second control path: a link can be revoked without exposing the secret body and without waiting for TTL expiration.

Why this exists

One-time links are useful only while the sender still trusts the delivery channel. If a link is pasted into the wrong chat, copied into a ticket, or sent to the wrong person, the sender needs a quick revocation path.

The destroy token is not the secret. It is a separate revocation credential and must be delivered only to someone trusted to invalidate the link.

Recommended flow

  1. Create the secret with the shortest acceptable TTL.
  2. Send the public link through the normal channel.
  3. Keep the destroy token private or share it with a trusted operator.
  4. Destroy the link if the delivery context changes.

Example response

{
  "id": "9f31ab20",
  "url": "/s/9f31ab20",
  "destroyToken": "dt_demo_7b9c...",
  "expiresIn": 3600
}

api

HTTP API preview

demo contract

The examples below describe the expected backend contract for one-time secret links. The Try controls are UI stubs for a future connected backend.

POST /v1/secrets

Create an encrypted one-time secret and return a public link plus a destroy token.

usage 
{
  "secret": "DATABASE_URL=...",
  "ttl": 3600,
  "maxViews": 1
}
response 
{
  "id": "9f31ab20",
  "url": "/s/9f31ab20",
  "destroyToken": "dt_..."
}
try response 
{
  "ok": true,
  "id": "demo-created",
  "queued": false
}
GET /v1/secrets/{id}

Read a secret once. Depending on policy, the backend burns it immediately after successful read.

usage 
GET /v1/secrets/9f31ab20
Authorization: Bearer demo
response 
{
  "secret": "visible-once",
  "burned": true
}
try response 
{
  "ok": true,
  "secret": "demo response preview",
  "burned": true
}
POST /v1/destroy

Destroy a secret before it is opened. This is intended for the sender or a trusted recipient.

usage 
{
  "destroyToken": "dt_..."
}
response 
{
  "destroyed": true,
  "reason": "manual"
}
try response 
{
  "ok": true,
  "destroyed": true,
  "reason": "manual"
}

Return aggregate public counters for landing-page statistics. No secret body is exposed.
